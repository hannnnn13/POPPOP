## 한눈에 보기

- **기간:** 2026년 11월 2일 ~ 현재
- **상태:** 진행 중 (과제 제출 후에도 계속 고쳐 나갈 예정)
- **역할:** 개인 활동. 테마 선택, 설정, 글 작성, 배포, 점검을 모두 혼자 했고, AI(Claude)를 페어 프로그래머로 활용했습니다.

## 왜 만들었나요

초급프로젝트 과제로 시작했습니다. 목표는 두 가지였습니다.

1. Hugo 테마의 예시 내용을 모두 걷어 내고, 나를 소개하는 사이트로 바꾸기
2. main에 push하면 GitHub Actions가 알아서 빌드하고 공개 사이트를 갱신하는 구조를 직접 만들어 보기

## 어떻게 만들었나요

### 1. 테마 고르기

Hugo Themes에서 **No Fate** 테마를 골랐습니다. 프로젝트와 학습 기록을 나눠 보여 주는 구조, 검색, 다크 모드, 한국어 번역이 기본으로 들어 있어 기능을 새로 만들지 않고 내용에 집중할 수 있었습니다.

### 2. 배포 준비

테마 저장소를 ZIP으로 내려받고, 수업에서 받은 준비 스크립트로 GitHub Actions 워크플로를 만들었습니다. 저장소 설정에서 Pages의 배포 방식을 GitHub Actions로 바꾼 뒤, push할 때마다 빌드와 배포가 자동으로 실행되는 것을 확인했습니다. 스크립트를 쓴 이유는 테마에 필요한 파일과 하위 경로(`/POPPOP/`) 보정을 한 번에 처리해 주기 때문입니다.

### 3. 예시 내용 정리

테마에 들어 있던 가상의 글, 프로젝트, 이미지, 예시 데이터를 하나씩 지우고 메뉴와 문구를 한국어로 바꿨습니다.
