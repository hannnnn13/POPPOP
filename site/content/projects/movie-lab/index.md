## 한눈에 보기

- **시기:** 2026년 10월, 초급프로젝트 4주차 수업 실습
- **상태:** 완료
- **역할:** 개인 실습. 수업에서 받은 시작 코드로 직접 따라 하며 배포까지 했습니다.

Vue로 만든 화면에 TMDB의 실제 영화 데이터를 불러와 보여 주는 페이지입니다.

## 보안 관점에서 본 점

이 페이지는 방문자가 자신의 TMDB API 키를 직접 입력하는 방식입니다. 키가 소스 코드와 배포 파일에 들어가지 않아, 저장소가 공개되어 있어도 키가 새지 않습니다.
